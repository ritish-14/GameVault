About GameVault

GameVault is a simple game collection project.

Organise your library, discover new favourites, and keep your collection in one place.

Project features

  • A clean home page introducing the project.
  • A separate About page describing the project.
  • Responsive styling for desktop and mobile screens.
  • A Git workflow demonstrating commits, branches, merging, ignoring files, and reverting.
